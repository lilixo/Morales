# Morales Viajes

Examen final de Diseño Web, desarrollado en Angular.

Entrega: carpetas `src` y `public`.

Reemplaza ambas carpetas en el proyecto Angular original y ejecuta `npm install` y `ng serve -o` desde la carpeta que contiene `angular.json`.

Incluye cabecera, pie de página, Principal con carrusel de dos imágenes y Contáctenos con formulario de pedidos. Los botones Cancelar y Enviar son de muestra, sin funcionalidad.
